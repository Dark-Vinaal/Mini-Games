# Mini Games

A collection of interactive mini-games playable either directly in the terminal via CLI or in the web browser using HTML, CSS, and JavaScript. Built to sharpen logic, explore game loops, and practice full-stack and command-line development through fun, bite-sized projects.

---

## 🎮 About

This repository houses lightweight, playable games across two formats:

- **CLI Games**: Terminal-based games driven by command-line interfaces and keyboard inputs.
- **Web Games**: Browser-ready games built with standard web technologies for quick, casual play.

Whether running scripts locally in your terminal or opening HTML files in a browser, this collection serves as a playground for practical programming and game mechanics logic.

---

## 🕹️ Games Included

| Game | Interface | Tech Stack | Description |

| **Number Guessing Game** | CLI | `Python`, `GoLang`, `Java`, `C++`, `C`, `Dart`, `Express.js` | A terminal-based game where you guess a randomly generated number within a set range. |
